# NATE-PowerHub
KELVINATE Power Hub is a power bank rental service based in Uyo, Akwa Ibom, aimed mainly at UniUyo students (campus locations, exam-season offers, a “Campus Plan”). A customer finds a station, picks a power bank by capacity, pays, collects it, then returns it at any station before time runs out. Late returns attract fees.



# KELVINATE Power Hub

Power bank rental web application for Uyo, Nigeria. Starting with University of Uyo campus stations.
